# TaskFlow

A task management REST API built with **Spring Boot 4**, **Java 25**, **Spring Data JPA**, and an **H2** in-memory database. The project also includes a Docker-based frontend UI that connects to the backend.

This is a simple application to practice Spring Boot that allows:
- Creating a task
- Updating a task
- Removing a task

---

## Tech Stack

- **Java 25**
- **Spring Boot 4.0.6**
- **Spring Data JPA**
- **Spring MVC**
- **Spring Validation**
- **H2 Database** (in-memory)
- **Maven**
- **Docker / Docker Compose**

---

## Prerequisites

- [Java JDK 25+](https://www.oracle.com/java/technologies/downloads/)
- [Apache Maven 3.9+](https://maven.apache.org/download.cgi)
- [Docker](https://www.docker.com/) (optional, for the frontend UI)

---

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/davidAST/TaskFlow.git
cd TaskFlow
```

### 2. Run the application

Open the project in your IDE and run the `TaskApplication` main class.
